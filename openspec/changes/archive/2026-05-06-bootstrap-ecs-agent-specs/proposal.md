# Bootstrap ECS Agent OpenSpec

## Why

The repository now contains a Python LangGraph ECS agent, a local Agent Chat UI, SDK examples, and operational documentation. Future changes need a durable source of truth so an AI assistant or developer can understand existing behavior before modifying code.

## What Changes

- Add OpenSpec current-state specifications for agent runtime, configuration, local frontend, and developer workflow.
- Add an archived bootstrap change documenting why the specs were introduced.
- Update README commands so installation, runtime, verification, GitHub, and OpenSpec workflows are discoverable.

## Impact

- Future development should consult `openspec/specs/` before changing behavior.
- The README becomes the operational command index for the project.
